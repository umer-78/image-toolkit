Convolution is not correlation

Almost every "convolution" in image code is correlation: the kernel slides in place, no flip. For symmetric kernels (box, Gaussian) they match. For Sobel they differ by sign — correlate(sobel) == -convolve(sobel).

This demo exposes both mental models in the UI notes; edges use correlation like the Python correlate() path.

Separable Gaussian

A 2D Gaussian is rank-1: two 1D passes cost O(k) per pixel instead of O(k²). The kernel line counts above show the speed-up for the current σ.

Padding reflects (not zeros), so edges do not invent a black frame for the detector to find.
